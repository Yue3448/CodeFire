# Project instructions

This is a private personal coding activity dashboard.

Goal:
- Build a beautiful gamified dashboard for coding statistics.
- Use WakaTime API as the data source.
- This is not intended as an open-source portfolio project.

Rules:
- Keep WakaTime API key only in .env.
- Never expose secrets to frontend code.
- Prefer simple, maintainable code.
- Prioritize working local version first.
- Use dark UI with RPG/progression feel.
- Do not overcomplicate architecture.
